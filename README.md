# PINN-for-Multiphysics-Modeling

This code is for our paper: *Efficient multiphysics system modeling enabled by data-free physics informed neural networks*

## 1. System Requirements

The code has been tested with the following configuration:

- Python 3.12.4
- PyTorch 2.2.2+cu118 (CUDA 11.8, available: True)

## 2. Model Overview

This repository provides the PINN model codes for the proton exchange membrane fuel cell (PEMFC) and the lithium-ion battery (LIB) presented in the paper. The two models are stored in separate folders, and each folder contains a `readme.txt` file describing how to use the corresponding model.
